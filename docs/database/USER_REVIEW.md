# DB 연결 사용 안내

로컬 앱은 이제 Supabase에 프로필·공고·신청·약속·채팅 등을 저장한다. 실제 두 계정으로 공고 작성과 신청·수락을 확인했다.

- 실행: `npm run dev` (`.env.local`의 `VITE_AUTH_MODE=supabase-test`).
- 로그인: 테스트 번호 `01000000001`~`01000000003`, 인증번호 `123456`.
- 공용 테스트 계정이므로 개인정보는 입력하지 않는다. 실제 SMS 본인인증은 아니다.
- 두 브라우저에서 서로 다른 계정으로 로그인해 상대방의 공고에 신청할 수 있다.
- 채팅방을 양쪽에서 열면 새 메시지가 새로고침 없이 실시간으로 표시된다. 실제 로컬 검증 측정값은 831ms였다.
- 앱 시작 때 화면 전체를 가리던 데이터 로딩 대기 화면은 제거했다. 보호 화면의 개인 데이터가 준비되는 짧은 동안에는 앱 틀 안에 자리 표시자만 보인다.
- 기존 로컬 시연은 `?demo=1`로 접근한다.

Vercel Preview 배포와 실제 DB 흐름 검증을 완료했다. 최신 Realtime Preview는 `https://yumidang6-4uqlyufc7-jjackbb-projects.vercel.app`이며 새로고침 없는 메시지 도착을 확인했다. 운영 주소 반영은 공개 테스트 로그인을 Production에 여는 명시적 승인 대기 상태다. [완료·미완료 범위와 재개 순서](INTEGRATION.md)를 참고한다.

사용자가 재검증·배포 재시도를 승인했지만 재시도도 같은 시스템 오류로 거부됐다. 추가 사용자 승인이 필요한 상태는 아니다.
