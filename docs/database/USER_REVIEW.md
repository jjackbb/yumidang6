# DB 연결 사용 안내

로컬 앱은 이제 Supabase에 프로필·공고·신청·약속·채팅 등을 저장한다. 실제 두 계정으로 공고 작성과 신청·수락을 확인했다.

- 실행: `npm run dev` (`.env.local`의 `VITE_AUTH_MODE=supabase-test`).
- 로그인: 테스트 번호 `01000000001`~`01000000003`, 인증번호 `123456`.
- 공용 테스트 계정이므로 개인정보는 입력하지 않는다. 실제 SMS 본인인증은 아니다.
- 두 브라우저에서 서로 다른 계정으로 로그인해 상대방의 공고에 신청할 수 있다.
- 기존 로컬 시연은 `?demo=1`로 접근한다.

**아직 새 Vercel 배포는 완료하지 못했다.** 마지막 채팅 버튼 수정의 브라우저 재검증과 배포 단계에서 자동 승인 검토가 처리 용량 오류로 실행을 거부했다. [완료·미완료 범위와 재개 순서](INTEGRATION.md)를 참고한다.

사용자가 재검증·배포 재시도를 승인했지만 재시도도 같은 시스템 오류로 거부됐다. 추가 사용자 승인이 필요한 상태는 아니다.
